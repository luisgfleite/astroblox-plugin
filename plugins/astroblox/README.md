# AstroBlox

Crie VFX, modelos 3D e interfaces (GUI) para Roblox descrevendo o que você quer em português. Interfaces vêm com fontes do tema do jogo, fundo gerado colorível em movimento e animações. Animação de personagens chega em breve. O plugin mostra o orçamento em créditos antes de gerar, baixa malhas, texturas, sons e o instalador Luau, e monta o efeito no Roblox Studio pelo servidor MCP do Studio.

## Instalação

- **Claude Code:** `/plugin marketplace add https://astroblox.site/claude/marketplace.json` e depois `/plugin install astroblox@astroblox`.
- **Codex:** `codex plugin marketplace add luisgfleite/astroblox-plugin` e depois `codex plugin add astroblox@astroblox`.

No primeiro pedido o agente mostra um código. Aprove em https://astroblox.site/conectar com a sua conta AstroBlox. Presets do catálogo são gratuitos; gerações originais usam os créditos do seu plano.

## Ferramentas

| Ferramenta | O que faz |
| --- | --- |
| `astroblox_login` | Conecta a conta por código aprovado no navegador |
| `astroblox_account` | Plano, saldo de créditos e pedidos recentes |
| `astroblox_plans` | Planos, recarga e links para assinar |
| `astroblox_aura_catalog` | Busca e baixa presets gratuitos |
| `astroblox_create` | Abre um preset ou calcula o orçamento de uma geração |
| `astroblox_confirm` | Inicia a geração depois que o usuário aprova o orçamento |
| `astroblox_job` | Acompanha um pedido e baixa os arquivos |

Guia completo: https://astroblox.site/guia
