# AstroBlox para Codex e Claude Code

Crie **VFX, modelos 3D, interfaces animadas e animações R15** para Roblox a partir de uma descrição, e instale tudo no Roblox Studio pelo seu agente.

Versão 1.3.2 · [astroblox.site](https://astroblox.site)

## Instalar no Codex

```bash
codex plugin marketplace add luisgfleite/astroblox-plugin
codex plugin add astroblox@astroblox
```

## Instalar no Claude Code

```
/plugin marketplace add luisgfleite/astroblox-plugin
/plugin install astroblox@astroblox
```

## Começar

1. Peça algo ao agente, por exemplo: *"crie uma aura de fogo azul para o meu personagem"*.
2. O agente mostra um código de 8 letras. Aprove em [astroblox.site/conectar](https://astroblox.site/conectar) com a sua conta AstroBlox.
3. Veja o orçamento em créditos, aprove e o agente gera e instala no Studio (ative o servidor MCP do Roblox Studio em **Assistant → Manage MCP Servers**).

Presets do catálogo são gratuitos. Gerações originais usam os créditos do seu plano: [planos](https://astroblox.site/#planos) · [guia completo](https://astroblox.site/guia).

## Atualizar

```bash
codex plugin marketplace upgrade astroblox
```

No Claude Code: `/plugin marketplace update astroblox`.
